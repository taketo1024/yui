# ssi over the Lamm bundle of strongly invertible knots

Two experiments over `lib-link/resources/inv_link_lamm/` (all strongly
invertible knots up to 10 crossings; every diagram is a transvergent PD in
KnotInfo chirality, see the bundle's README). Computed 2026-07-09 on branch
`sym-si-diagram`.

Invariant: `ssi = (s̲, s̄)` via `yui_kh::khi::ssi_invariant` over `𝔽₂[H]`
with `c = H`, unreduced.

## Experiment 1: `ssi(K, τ)` for every diagram

All 326 diagrams of the bundle (each inversion class separately),
with `SymBuildConfig::default()`; every knot took well under a second.

Result: `s̲ ≠ s̄` occurs for exactly 7 knots (8 diagrams), **all
non-alternating**:

| knot | class `a` | class `b` |
|---|---|---|
| `8_21`   | `(2, 2)`   | `(2, 4)` |
| `9_46`   | `(-2, 0)`  | `(-2, 0)` |
| `10_141` | `(0, 0)`   | `(0, 2)` |
| `10_144` | `(2, 2)`   | `(2, 4)` |
| `10_160` | `(2, 4)`   | (single class known) |
| `10_162` | `(-4, -2)` | (single class known) |
| `10_165` | `(-4, -2)` | (single class known) |

Observations:

- For `8_21`, `10_141`, `10_144` the two strong inversions (`τx`, `τy` of the
  doubly transvergent template-X diagram) have **different `ssi`** — an
  invariant-level proof that the two classes are inequivalent, and a
  demonstration that `ssi` depends on the involution, not just the knot,
  already at ≤ 10 crossings.
- `9_46` gives `(-2, 0)` on both classes — the mirror of the known `(0, 2)`
  (the bundle is KnotInfo chirality, opposite to the positive-writhe `9_46`
  of our ssi papers); an end-to-end consistency check.
- `10_160`, `10_162`, `10_165` are new members of the `s̲ ≠ s̄` family; like
  `9_46` they come from Lamm's `C₁` (trefoil) template. Only one inversion
  class is known for them (they have no cyclic period 2, so template X does
  not apply).
- Every **alternating** diagram — including all 190 two-bridge ones — has
  `s̲ = s = s̄`. Conjecture: this holds for every strong inversion of an
  alternating knot.

## Experiment 2: `ssi((K, τa) # (−K, −τb))` for all two-class knots

For each of the 115 knots carrying both classes `a`, `b` in the
bundle, the equivariant connected sum `J = (K, τa) # (−K, −τb)` was formed by
`InvLink::conn_sum` + `mirror` (`J` is slice as a plain knot, but possibly not
equivariantly slice), and `ssi(J)` computed with
`mode = MinFill`, `cut = Auto(2)`, `h_range = ..= 1`, computing the mirror
instead whenever `writhe(J) < 0` (using `ssi(K) = (−s̄(K̄), −s̲(K̄))`).
Total wall time ≈ 25 min; worst pair 47 s at 32 crossings.

Result: `ssi(J) ≠ (0, 0)` for **exactly three pairs** — precisely the knots
whose two classes already differ in Experiment 1:

| pair | `ssi(a # -b)` |
|---|---|
| `8_21`   | `(-2, 0)` |
| `10_141` | `(-2, 0)` |
| `10_144` | `(-2, 0)` |

Observations:

- `8_21` reproduces the previously computed nonzero example.
- The three values agree with component-wise additivity
  (`ssi(−K, −τ) = (−s̄, −s̲)`), e.g. `8_21`: `(2,2) + (−4,−2) = (−2,0)`.
  Additivity is *not* a theorem — it would contradict the vanishing on the
  equivariantly slice controls `(K,τ) # (−K,−τ)` whenever `s̲ ≠ s̄` — but no
  deviation from it appears in this range.
- **All pairs with `ssi(τa) = ssi(τb)` give `(0, 0)`, including `9_46`**,
  whose two classes are inequivalent. So no secondary (cork-type) effect is
  visible here: `ssi` does not obstruct equivariant sliceness of
  `(9_46, τa) # (−9_46, −τb)`.
