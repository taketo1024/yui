# yui (結)

[![build](https://github.com/taketo1024/yui/actions/workflows/test.yml/badge.svg)](https://github.com/taketo1024/yui/actions/workflows/test.yml)

`yui` is a collection of libraries for homology computations, with particular focus on *knot homology theories*, written in [Rust](https://www.rust-lang.org).

## Libraries

- [`yui-core`](./lib-core/) - The core library: algebraic traits, concrete numeric/polynomial/linear-combination types.
- [`yui-matrix`](./lib-matrix/) - Sparse and dense matrix computations, based on [nalgebra](https://nalgebra.org).
- [`yui-homology`](./lib-homology/) - Generic chain complex and homology computations.
- [`yui-link`](./lib-link/) - Knots and links (planar diagrams, braids).
- [`yui-kh`](./lib-kh/) - Khovanov homology.

## Binaries
- [`ykh`](./bin-ykh/) - Khovanov homology computations.

## Knot/link data

`Link::load(name)` and `Braid::load(name)` (and the `ykh` CLI when given a name like `3_1`) read from an external user-data directory:

1. `$YUI_DATA_DIR` if set.
2. Otherwise the platform user-data dir:
    - macOS: `~/Library/Application Support/yui/`
    - Linux: `${XDG_DATA_HOME:-~/.local/share}/yui/`
    - Windows: `%APPDATA%\yui\`

Inside that dir, data is partitioned by kind, e.g. `<data_dir>/links/3_1.json`, `<data_dir>/braid/3_1.json`.

To populate it from the [KnotInfo](https://knotinfo.org/) database:

```bash
python3 scripts/fetch-knot-data.py            # writes to the default data dir
python3 scripts/fetch-knot-data.py --out DIR  # or to a custom directory
```

### Data sources

- PD codes, braid words and invariants come from **KnotInfo**:

  > C. Livingston and A. H. Moore, *KnotInfo: Table of Knot Invariants*,
  > <https://knotinfo.org/>

- The transvergent (axis-symmetric) diagrams of strongly invertible knots up to 10 crossings,
  bundled in [`resources/inv_link/`](./resources/inv_link/), are built from the templates of:

  > C. Lamm, *Symmetric diagrams for all strongly invertible knots up to 10 crossings*,
  > <https://arxiv.org/abs/2210.13198>
